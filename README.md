# filee-web

Website and promo material for [Filee](https://github.com/KnifeLemon/Filee). The app itself lives in the Filee
repository; keep it checked out next to this one (`repos/Filee`, `repos/filee-web`).

| Folder | What it is |
|---|---|
| [`site/`](site/README.md) | The [filee.sh](https://filee.sh) website, deployed to Cloudflare Workers |
| [`marketing/`](marketing/README.md) | Renders the promo video, carousel slides, Open Graph cards and README media |
